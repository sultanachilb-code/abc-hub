ABC Operations Hub — Home page folders (Option A) — separate package
Install: copy index.html into the abc-hub folder (replace), then deploy.
Tenant Management and Policies & Procedures become two iPhone-style folders under "Folders".
Tap a folder: it zooms open over a blurred home. Tap outside, press Esc, or swipe down to close.
Search still finds every tool inside the folders.

To go back: copy revert/index.html into the abc-hub folder (replace), then deploy.
This package only touches index.html, so it can be installed or removed on its own,
before or after the handover fixes.
